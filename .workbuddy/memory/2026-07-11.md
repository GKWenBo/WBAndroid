## 构建 demo_03（W2 Compose UI）
- 复制 demo_02 骨架 → `Demo/demo_03_compose_ui/`（目录名 demo_03），包名 com.wb.example.demo_03。
- 关键配置：
  - `settings.gradle.kts` 在 `pluginManagement.plugins` 统一声明 `kotlin = "2.3.20"`，并加入 `org.jetbrains.kotlin.plugin.compose` 版本 2.3.20（compose 编译器插件，必须显式带版本；kotlin.android 不显式声明，靠 AGP 自动应用）。
  - 模块 `build.gradle.kts` 用 `alias(libs.plugins.android.application)` + `alias(libs.plugins.kotlin.compose)`，`buildFeatures { compose = true }`，Compose 依赖走 BOM（`androidx.compose.compose-bom` 2025.06.00）。
  - 新增依赖：ui / ui-graphics / ui-tooling-preview / material3 / activity-compose / lifecycle-viewmodel-compose / navigation-compose。
- 代码：`MainActivity`（setContent 入口）、`ui/theme/Theme.kt`（深色模式换肤）、`ui/AppNavigation.kt`（NavHost 登录→列表 + 共享深色开关）、`ui/LoginScreen.kt`（TextField/Button/Switch）、`ui/ListScreen.kt`（LazyColumn + Scaffold/TopAppBar）。含大量 iOS↔Compose 对照注释。
- 风险：Kotlin/Compose BOM 版本为估算（沙箱无 Android SDK 无法构建验证），用户本地 Sync 可能需微调版本（同 demo_02 的迭代方式）。已写入 README 坑位说明。
