## demo_02 Gradle Sync 报错修复（23:20）
- 报错：`Error resolving plugin [id: 'org.jetbrains.kotlin.android', version: '2.3.20']` —— The plugin is already on the classpath with an unknown version。
- 根因：AGP / Android Studio 会自动把 Kotlin Gradle 插件注入 classpath；我在模块里用 `alias(libs.plugins.kotlin.android)` 又显式指定版本，与注入版本冲突。这也解释了 `demo_01` 未声明 kotlin 插件却能编译 .kt。
- 修复：`Demo/demo_02/app/build.gradle.kts` 模块改为 `id("org.jetbrains.kotlin.android")` 不写版本；`libs.versions.toml` 删除 `kotlin` 版本与 `kotlin-android` plugin 条目。`libs.androidx.coroutines` 库依赖保留。
- 经验（修正）：**在该环境下 Android 工程的 Kotlin 插件连 `id(...)` 都不要显式声明**——AGP 9.2.1 会自动注入并应用，写了反而重复报 `Cannot add extension with name 'kotlin'`。正确写法是模块 `build.gradle.kts` 只保留 `alias(libs.plugins.android.application)`，完全对齐 `demo_01`。协程等只作普通库依赖 `libs.androidx.coroutines`。后续 demo_03/04/05 务必沿用此写法，不要再声明 Kotlin 插件。
