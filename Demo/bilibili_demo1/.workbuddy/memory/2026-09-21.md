## 真正的编译错误（用户自己加的跳转代码）

- 报错位置：`MainActivity.kt:46`，`intent.setClass(MainActivity, MainActivity2)`。
  4 条 Kotlin 错误：`Classifier 'MainActivity' does not have a companion object, so it cannot be used as an expression` + `Argument type mismatch: actual type is 'Unit', but 'Context'/'Class<*>' was expected`。
  **Kotlin 里类名不能当表达式用**，必须写 `Intent(this, MainActivity2::class.java)`（或 `intent.setClass(this, MainActivity2::class.java)`）。
- 修复：`val intent = Intent(this, MainActivity2::class.java); startActivity(intent)`。
- 顺带把 `MainActivity2` 从 `ComponentActivity` 改成 `AppCompatActivity` + ViewBinding + 同样的 edge-to-edge insets。
  原因：应用主题是 `Theme.AppCompat.DayNight.NoActionBar`，`AppCompatDelegate` 只有在 AppCompatActivity 下才会生效，
  否则第二页在深色模式下不会跟随（与第一页不一致），且 ViewBinding 是本项目既定约定。
- 验证：`./gradlew :app:build` BUILD SUCCESSFUL（含 lint + 单测 + release）；装到 emulator-5554，
  点「跳转」后 `topResumedActivity=.../.MainActivity2`，页面显示「我创建的第一个安卓页面」，无 FATAL；
  按返回键回到 `.MainActivity`。
